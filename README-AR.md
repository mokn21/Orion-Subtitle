# Orion Subtitles — البناء السحابي

هذه النسخة مبنية تقنيًا على iPlay5 وChiaki-ng. الهدف هو إنتاج IPA حقيقي للبث المحلي من PS5 داخل تطبيق iPadOS، مع Vision OCR وترجمة قابلة للتحقق داخل التطبيق. لا تُعدّ الترجمة أو الاتصال الميدانيان مُختبرين قبل تشغيل التطبيق على iPad حقيقي متصل بـPS5.

## ما تحتاجه

- حساب GitHub مجاني.
- مستودع GitHub عام Public لهذا المشروع.
- iPad يعمل بـ iPadOS 15 أو أحدث.
- SideStore مثبتًا على iPad.
- PS5 على الشبكة نفسها عند اختبار البث.

## طريقة البناء دون كتابة أوامر

1. ارفع محتويات هذا المجلد إلى مستودع GitHub عام.
2. افتح تبويب **Actions** في المستودع.
3. اختر **Build Orion IPA** من القائمة.
4. اضغط **Run workflow** ثم اضغط الزر الأخضر للتشغيل.
5. انتظر حتى تظهر علامة النجاح.
6. افتح نتيجة التشغيل واضغط على ملف **orion-subtitles-ipa** لتنزيله إلى Windows.
7. فك الضغط عن الملف الذي نزلته؛ ستجد `Orion-Subtitles.ipa`.
8. افتح SideStore في iPad، واختر إضافة IPA من الملفات، ثم اختر الملف.

لا تحتاج عملية البناء إلى Mac أو Xcode على جهازك؛ GitHub يشغّلها على macOS سحابي. لا نضع Apple ID أو كلمة مرور أو شهادة توقيع في GitHub. SideStore يعيد توقيع IPA على جهازك بحساب Apple الخاص بك.

## حدود الخطة المجانية

البناء المجاني يعتمد على مستودع عام واستخدام standard macOS runner. هذا ليس ضمانًا أبديًا؛ GitHub يمكن أن يغيّر سياساته أو يوقف التشغيل إذا كان الحساب أو المستودع لا يطابق شروطه. IPA الناتج غير موقّع، وهذا مقصود لأن SideStore يعيد توقيعه. الحساب المجاني في SideStore يفرض حدًا أقصى لثلاثة تطبيقات فعالة و10 App IDs مختلفة خلال أسبوع، وتنتهي التطبيقات عادة بعد 7 أيام وتحتاج إلى تحديث.

## اختبار النجاح

بعد التثبيت، يجب أن يظهر Orion Subtitles على iPad. بعد تفعيل Remote Play على PS5 والسماح بالشبكة المحلية، يجب أن يتم اكتشاف PS5 والاقتران بواسطة PIN ثم ظهور بث اللعبة. ظهور شاشة الواجهة وحده لا يثبت نجاح Remote Play.

## ملاحظة الترخيص

يحتوي المشروع على أجزاء AGPL-3.0 من iPlay5 وChiaki-ng. عند توزيع نسخة معدلة يجب الالتزام بالترخيص ونشر المصدر المطلوب وفقه.
